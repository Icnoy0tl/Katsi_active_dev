# Small Contributions Guideline

# Keep it short:

Keep your functions in 60 to a hard maximum of 80 lines of code, spaces and comments dont count

# Keep it clean:

No magic numbers, no variable names that only you understand. Make sure that your code is understandable, use constants and dont worry about long names in variables
is better that everyone understand the code than having short names

# Not to deep

Keep everything that is nested(functions, if statements, etc) only 2 to 3 levels(hard limit)

# Well documented

Keep comments only for small notes, TODOs, short explanations, dont make long ass comments explaining what the code / func does,
if it needs that much of an explanation then please add it to the readme
